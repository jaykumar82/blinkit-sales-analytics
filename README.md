# Blinkit Sales Analytics Dashboard

## Overview
- Developed an interactive Power BI dashboard to analyze Blinkit sales performance, customer preferences, and outlet trends.
- Visualized sales distribution, product categories, outlet performance, and customer buying behavior to support business decision-making.

## Tools Used
- Power BI
- Excel

## Key Features
- Sales and KPI tracking
- Outlet performance analysis
- Item category insights
- Fat content analysis
- Tier and outlet size comparison
- Interactive filters and dynamic visuals

## Key Insights
- Tier 3 outlets generated the highest overall sales.
- Low-fat products showed higher customer demand.
- Fruits and snack items contributed significantly to total revenue.
- Medium-sized outlets demonstrated strong sales performance across locations.
